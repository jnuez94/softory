# Sources

Where the role profiles and skills come from. Agents don't load this page; it's kept for the people who maintain softory.

## Darwin, UX Designer

- Jakob Nielsen, [10 Usability Heuristics for User Interface Design](https://www.nngroup.com/articles/ten-usability-heuristics/) (Nielsen Norman Group).
- [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) (W3C).
- Marty Cagan, [The Four Big Risks](https://svpg.com/four-big-risks/): usability belongs to the designer.
- Vercel, [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines).

## Greg, Product Manager

- Marty Cagan, [The Four Big Risks](https://svpg.com/four-big-risks/) (SVPG): value and viability belong to the PM.
- [The Scrum Guide](https://scrumguides.org/scrum-guide.html): product owner accountability for backlog ordering and the definition of done.
- Bill Wake, [INVEST in Good Stories, and SMART Tasks](https://xp123.com/articles/invest-in-good-stories-and-smart-tasks/).
- [Gherkin reference](https://cucumber.io/docs/gherkin/reference/) for Given/When/Then.

## Quinn, Principal Engineer

- Will Larson, [Staff archetypes](https://staffeng.com/guides/staff-archetypes/) (StaffEng): Quinn combines the Tech Lead and Architect archetypes.
- Amazon, [Principal Engineering Community Tenets](https://amazon.jobs/en/landing_pages/pe-community-tenets): exemplary practitioner, balanced and pragmatic, illuminate and clarify, respect what came before.
- Michael Nygard, [Documenting Architecture Decisions](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
- Google, [Engineering Practices: Code Review](https://google.github.io/eng-practices/review/).
- Marty Cagan, [The Four Big Risks](https://svpg.com/four-big-risks/): feasibility belongs to the tech lead.

## Senior Software Engineer: shared expectations

- Dropbox, [Engineering Career Framework](https://dropbox.github.io/dbx-career-framework/): ownership, craft, and collaboration at senior levels.
- Google, [Engineering Practices](https://google.github.io/eng-practices/): the CL author's guide and the reviewer's guide.
- Winters, Manshreck, and Wright, [Software Engineering at Google](https://abseil.io/resources/swe-book).
- Ham Vocke, [The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html).
